# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its
Code of Conduct. The full text is maintained upstream at:

> https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project (filing issues, opening pull
requests, joining discussions), you agree to abide by it.

## Enforcement

Reports of unacceptable behavior go through GitHub's private
reporting channel for this repository:

> https://github.com/mikedconcepcion/CuttleDB/security/advisories/new

The same private channel is used for both security disclosures and
Code of Conduct reports. It is visible only to repository
maintainers and supports threaded follow-up, embargoed coordination,
and confidential resolution.

We will acknowledge receipt within **3 business days** and aim to
respond substantively within **10 business days**.
