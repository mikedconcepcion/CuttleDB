Why CuttleDB?

Most modern stacks pull in three or four databases to do what one process can do at the substrate level. CuttleDB collapses them.

⚡

Substrate-level speed

Column store with running aggregates. COUNT and SUM are O(1). AVX2 SIMD predicate scans. Faster than SQLite :memory: on read-path aggregates at 1K-row workloads despite TCP overhead.

⊹

Vector search built-in

First-class VEC columns + HNSW index. Top-10 over 10K vectors in 2ms. At 100K × 128: 12.7× faster than the AVX2+FMA brute-force baseline. No Pinecone, no separate service.

⇄

Real-time push

SUB / UNSUB per-table change feed. Every mutation triggers a >EVT line on every subscribed socket. LOG ring buffer for replay after disconnect.

🔒

Enterprise-tier security

Multi-token auth, NDJSON audit log, TLS, --max-conn DoS cap, rate limit, structured slow-query log, HTTP /health probe, Prometheus /metrics.

⛁

Durable, transactional

ACID transactions: BEGIN / COMMIT / ROLLBACK. Write-ahead log with CRC32 frames + mid-transaction kill replay (exercised by integration tests).

⌂

One self-contained binary

Under 1 MB per platform. No JVM, no Python on the server side, no Redis, no SQLite library. Copy the binary, run it. Multi-platform CI: Linux + macOS + Windows.

Quickstart → Python

Open a handle, create a typed table, insert, query.

from cuttledb import CuttleDB, ColType

with CuttleDB.connect("127.0.0.1", 7780) as db:
    hid = db.open()
    tid = db.create(hid, "memory", [
        ("text",      ColType.STRING),
        ("embedding", ColType.VEC, 768),
    ])

    db.insert(hid, tid, ["hello world", [0.1, 0.2, ...]])

    # Vector KNN — AVX2 cosine + partial sort in one C call
    hits = db.knn(hid, tid, col=1, k=5, query=[0.15, 0.18, ...])
    for row_id, score in hits:
        print(score, db.get(hid, tid, row_id))

    # Real-time push — subscribe + drain events
    db.sub(hid, tid)
    for evt in db.poll_events(timeout=1.0):
        print("changed:", evt)

Verify a release

Every binary ships with a sigstore .cosign.bundle — signature + cert + Rekor transparency-log inclusion proof. 

# 1. Checksum
sha256sum -c SHA256SUMS.txt

# 2. Signature (requires cosign v2.0+)
cosign verify-blob \
  --bundle cuttledb-server-linux-x64.cosign.bundle \
  --certificate-identity-regexp ".*" \
  --certificate-oidc-issuer-regexp ".*" \
  cuttledb-server-linux-x64

Cross-reference Rekor entries at search.sigstore.dev. Full security policy: SECURITY.md.
